## Purpose
Write the problem statement, 2-3 testable questions and measurable decision rules. This produces the one-page brief for Gate G1.

## Before you run it: attach or prepare
- Verified gap, chosen study and sources
- Brief template (one_page_brief.md)

## Prompt (verbatim from the course Instructions PDF)
```text
Here is my verified gap [GAP], selected study [IDEA] and source evidence [SOURCES]. Write one precise research problem, two or three testable research questions, and hypotheses only where appropriate. For each question identify the input data, comparator, independent/dependent variables when relevant, evaluation metric, meaningful success threshold or decision rule, and an observation that would contradict my expectation. Separate the contribution I intend to investigate from a contribution already demonstrated. Flag overbroad questions and provide a one-page research brief that can be reviewed before implementation.
```
**Project values for the brackets:** [GAP], [IDEA], [SOURCES] = your outputs from Prompts 02-04, checked against the original papers.

Prompt text above is copied from the course Instructions PDF. Never paste invented numbers.

## What you must verify yourself
- [ ] Check each question can be answered by a number your code will produce.
- [ ] Make sure thresholds are set BEFORE seeing results.
- [ ] Remove any question that needs data you do not have.

## Save the output to
- one_page_brief.md (Gate G1 submission)
- Entry D5 in research_decisions.md

## Common mistakes
- Questions that are really goals ('improve labelling').
- No contradiction condition, so the hypothesis cannot fail.

## Done when
One-page brief complete, narrow, literature-supported and testable: Gate G1.
