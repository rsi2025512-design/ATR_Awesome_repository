Using my authentic prompt log [PROMPTS], code commits/diffs [CHANGES], errors and debugging notes [NOTES] and experimental evidence [FILES], prepare a concise AI-use and research-integrity report. For each significant AI-assisted activity record: task, tool, prompt/version, AI proposal, human decision, verification method, code/result change and outcome.
